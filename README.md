# OX POS Desktop — releases

Windows installers and the auto-update feed for the OX POS desktop app.

- **Download:** open the latest release and run `OX-POS-Setup-<version>.exe`.
- Installed apps check this repo automatically and update themselves.

Releases are published by the *Desktop release* workflow in `MarkZoneTech/ox-backoffice` — do not upload files here by hand.
